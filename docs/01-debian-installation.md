# Debian Installation

## Objective

Set up a physical Linux server using Debian Linux as the foundation of my cybersecurity homelab.

## Hardware Used

- HP Desktop
- Intel Pentium G2030 3.0 GHz
- 2 GB RAM
- 500 GB HDD

## Installation Process

I installed Debian Linux directly on the physical HP desktop using the graphical installer.

During the installation, I:

1. Selected the graphical installation option.
2. Configured the system language and keyboard layout.
3. Configured the network connection.
4. Created a standard Linux user account.
5. Configured the system storage.
6. Installed the base Debian system.
7. Installed the SSH server for remote administration.
8. Completed the installation and booted into Debian.

## Initial Verification

After the installation was completed, I successfully logged into the Debian system.

The machine was connected to my local network and prepared for remote administration.

## Result

The Debian installation was completed successfully, and the physical desktop is now being used as the base system for my Linux cybersecurity homelab.

## What I Learned

This stage helped me gain practical experience with:

- Installing Linux on physical hardware
- Basic Linux system setup
- Creating a Linux user account
- Preparing a Linux machine for remote administration
- Understanding the role of Debian as a server operating system
