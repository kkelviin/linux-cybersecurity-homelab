# Linux Cybersecurity Homelab

This repository documents my hands on Linux and cybersecurity homelab built using a physical HP desktop running Debian Linux.

The purpose of this project is to develop practical skills in Linux system administration, networking, remote server management, cybersecurity monitoring, and system hardening.

This is an ongoing project and will be updated as I continue learning and expanding the lab.

## Lab Environment

- Operating System: Debian Linux
- Hardware: HP Desktop
- CPU: Intel Pentium G2030 3.0 GHz
- RAM: 2 GB
- Storage: 500 GB HDD
- Administration Machine: MacBook
- Remote Administration: SSH

## Current Progress

So far, I have:

- Installed Debian Linux on physical hardware
- Created a standard Linux user account
- Installed and configured SSH
- Successfully connected to the server remotely
- Practiced Linux directory navigation
- Worked with basic Linux commands
- Explored Linux users and groups
- Learned file ownership and permissions
- Inspected the `/etc/passwd` file
- Started exploring Linux services
